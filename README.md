# EDU RESEARCH AI × SHARE · 2026–2027

Дербес веб-платформа прототипі. Google AI Studio-ға тәуелді емес: React + Vite интерфейсі және Express сервері ретінде іске қосылады. AI талдау модулі Gemini API-мен сервер арқылы байланысады; оны қолдану міндетті емес.

## Жергілікті іске қосу
1. Node.js 20 немесе одан жоғары нұсқасын орнатыңыз.
2. Жоба бумасында `npm install` орындаңыз.
3. Даму режимі: `npm run dev`. Интерфейс `http://localhost:5173` мекенжайында ашылады.
4. Өндірістік жинақ: `npm run build`, содан кейін `npm start`. Сервер `PORT` айнымалысын қолдайды.

## AI талдауын қосу
AI талдауы қажет болса, хостингтің серверлік Environment Variables бөліміне `GEMINI_API_KEY` кілтін енгізіңіз. Кілтті браузер кодына немесе ашық репозиторийге орналастырмаңыз. Кілт берілмесе, платформа AI талдаусыз демо режимінде жұмыс істей алады.

## Интернетке жариялау
Бұл архив өздігінен жарияланған сайт емес. Оны Node.js қолдайтын хостингке (мысалы, Render немесе Railway) жүктеп, Build command ретінде `npm install && npm run build`, Start command ретінде `npm start` орнатыңыз. Хостинг берген домен — платформаның нақты сілтемесі болады. Жариялау үшін хостинг аккаунтына иелік иесінің өзі кіруі және Deploy әрекетін растауы керек.

## Қазіргі прототиптің шектеулері
- Жобалар мен енгізілген жазбалар браузердің `localStorage` қоймасында сақталады; пайдаланушылар арасында ортақ синхрондау жоқ.
- Рөл ауыстыру интерфейстік демонстрация; серверлік авторизация емес.
- Нақты мектептік қолдану үшін Firebase/Supabase немесе басқа дерекқор, пайдаланушы аутентификациясы, серверлік рөлдік тексеру, аудит журналы, резервтік көшіру және қауіпсіздік тестілері қажет.
- Оқушының аты-жөні, ЖСН, телефон, мекенжай сияқты жеке деректерді AI сервисіне жібермеңіз. Тек анонимделген/жиынтық деректерді қолданыңыз.
- AI талдауы мұғалімнің кәсіби шешімін алмастырмайды.
